A make.fun entry for "Invent a Word We Need": it coins *corridance* — the mirrored sidestep two strangers do when each tries to let the other pass in a narrow hallway — and writes the word with its one-line definition to `/output/entry.txt`. The program is a deterministic Node 22 script using only the standard library, with a gate guard that refuses to write an empty, whitespace-only, or over-140-character entry.
